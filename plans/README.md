## Review record

All five plans were reviewed cold by a second model (different family) acting as
the executor, on 2026-08-16, before hand-off. Every claim it raised was verified
against the real code rather than accepted on trust. Nine defects were confirmed
and fixed in place:

- **002** — `"frankfurt.pmtiles"` used as a `startsWith` prefix also matched
  `frankfurt.pmtiles.backup`; split into `ALLOWED_R2_KEYS` (exact) vs
  `ALLOWED_R2_PREFIXES` (must end in `/`).
- **002** — a syntactically valid but out-of-bounds `Range` fell through to a
  `200` with the whole file; now returns `416`.
- **002** — added clamping for `w`/`h`/`q` transform parameters.
- **003** — `safeHref` accepted protocol-relative `//evil.example/p` via its
  `startsWith("/")` branch; now rejected before the single-slash check.
- **003** — `&` in a bare URL became `&amp;` in the visible link *text*; the
  label is now unescaped while the `href` stays encoded.
- **005** — `[A-Za-zÀ-ÿ0-9]` excluded `Ł Š Ć Ž Œ ẞ` (Polish/Czech victim names)
  and wrongly matched `×`/`÷`; replaced with `str.isalnum()`.
- **005** — the `is_structural` guard had been dropped, which would delete
  horizontal rules and table separators; restored, with a verification command
  for the cases it still does not cover.
- **005** — per-block `print` over ~3,500 files replaced with an aggregate count.
- **001** — the two bounding-box tests asserted literal arithmetic and exercised
  zero production code; rewritten to drive the real `build_theme()`, whose
  signature and both assertions were then executed against `scripts/geojson.py`.
- **001** — the existing CI job is named `check-coordinates`, not `validate`.

Two further review claims were checked and **rejected as false positives**:

- *"`from tests.conftest import load_script` will not resolve."* It does.
  Verified in an isolated project with the same `pythonpath = ["."]` config and
  an empty `tests/__init__.py`, under both `pytest` and `pytest tests/file.py`.
- *"004's collision handler causes runaway weekly duplication."* It does not.
  Pass 2 skips addresses already present in `osm_addr_slugs`, rebuilt from disk

## Findings considered and rejected

Recorded so they are not re-audited on the next run:

- **`sync_images.py` command injection**: not a finding. `subprocess.run` is
  called with a list argument, never `shell=True`, and the target argument is
  always prefixed with the bucket name (`f"{R2_BUCKET}/{key}"`), so a
  data-derived filename cannot be parsed as a CLI flag.
- **`slugify` path traversal**: not reachable. All five implementations reduce
  input through `[^a-z0-9]+` (or `[^\w\s-]`), so `/`, `\`, and dot-segments
  cannot survive. Verified by test in plan 004.
- **GeoJSON stacking hides all copies of a POI**: not possible. The
  `seen_themes` loop in `scripts/geojson.py:393-396` guarantees one primary
  marker per theme per location group; `stackHidden` is only set on non-primary
  members.
- **Committing `data/` to git, self-hosted PMTiles, the `overrides/` design,
  Web Speech API for TTS, API-native translation via `Accept-Language`, SPA on
  Cloudflare**: all decided tradeoffs documented in `PLAN.md`. Settled, not
  findings.
- **Hardcoded third-party OAuth credentials at `archive.py:18-24`**: real and
  serious, but excluded from these plans because the credentials belong to a
  third party's API (`api.frankfurthistory.app`), not to this project. Rotation
  is not the maintainer's to perform, and removing them from git history is a
  repo-wide decision (history rewrite on a public repo) that needs the owner's
  call, not an executor's. Escalated to the maintainer instead of planned.

## Findings deferred (real, but not in this batch)

Not rejected — just below the cut for this round. Ordered by leverage:

- **Article fetch has no cancellation** (`app/src/components/ArticlePanel.tsx:378-436`):
  no `AbortController` and no ignore-guard, so a slow fetch for POI A resolving
  after navigation to POI B renders A's content under B's URL. Small fix.
- **R2 route / `_headers` hardening beyond plan 002**: `app/public/_headers`
  sets headers only for `/*.pmtiles`; no CSP, `nosniff`, `Referrer-Policy`, or
  HSTS on a site rendering third-party scraped content.
- **Unpinned GitHub Actions**: `actions/checkout@v7` and
  `astral-sh/setup-uv@v8.2.0` in both workflows use mutable tags, not SHAs.
- **`NaN` search params reach MapLibre**: `mapSearchSchema` in
  `app/src/routes/$lang.tsx:30-36` uses `z.coerce.number()` without `.finite()`;
  `?lat=foo` yields `NaN`, and `NaN ?? default` does not fall back.
- **Negative coordinates silently dropped**: the regex at
  `app/src/components/ArticlePanel.tsx:402` is `[\d.]+`, so a negative longitude
  fails to parse and the POI gets no coordinates. Harmless for Frankfurt today;
  a latent bug if the dataset ever leaves the eastern hemisphere.
- **Hand-rolled frontmatter parser**: `scripts/merge.py:29-73` splits on `:`
  rather than parsing YAML. 17 real articles have a colon inside a quoted title
  and survive only because the quotes are preserved verbatim.
- **1.5 MB of GeoJSON fetched by four uncoordinated call sites** with no shared
  cache: `SearchDialog.tsx:38`, `NearbyPanel.tsx:64`, `ArticlePanel.tsx:139`,
  `prefetch.ts:20`.
- **Dead dependencies**: `boto3` (`pyproject.toml:8`) and `vinxi`
  (`app/package.json:41`) are not imported anywhere.
- **Two conflicting bounding boxes**: `scripts/geojson.py` enforces
  `49.5..50.5 / 8.0..9.5`; `.github/workflows/validate.yml` enforces
  `49.9..50.3 / 8.3..9.0`. A POI can pass one and fail the other.

## Direction findings (options for the maintainer, not defects)

Deliberately not turned into plans — these are product decisions:

- **Consume the records pipeline.** 2,868 records carrying 1,201 biographies and
  5,583 images are rebuilt weekly and read by nothing; the site still ships the
  849-file legacy markdown set. The largest latent value in the repo — but plan
  004's fragmentation must be resolved first, or the split records ship to users.
- **Multi-city is half-built.** `scripts/fetch_osm_stolpersteine.py:344` defaults
  to `['frankfurt-am-main', 'berlin']` and a Berlin scraper plugin exists at
  `scripts/initiatives/stolpersteine_berlin_de.py`, but
  `.github/workflows/archive.yml:49` only ever passes `--city frankfurt-am-main`.
- **A non-map index view.** 360 records have no coordinates and 402 POIs are
  hidden by the map stacking rule, so a meaningful fraction of the archive is
  unreachable through the map. A searchable name index would surface them.
- **Surface the record schema.** `person.birth_date`, `deported_to`, `fate`,
  `victim_group`, `laying_date`, and `artist` are populated and entirely
  unexposed in the UI.
